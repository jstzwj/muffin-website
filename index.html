文件、导出与主题。

文档存在哪里？

保存在本地，格式就是 .md。可以离线编辑，也可以用其他 Markdown 工具打开。

支持哪些导出格式？

原生导出 PDF、HTML 和 PNG。导出 Word、EPUB 等格式时，需要另行安装 Pandoc。

可以改主题吗？

内置 GitHub、Newsprint、Night、Pixyll 和 Whitey，也可以导入自己编写的 CSS 主题。

需要付费吗？

免费使用，源码采用 MIT 许可。问题反馈与开发进度都在 GitHub 仓库。
