# Muffin

**A native, lightweight, WYSIWYG Markdown editor.**

Muffin is a block-level WYSIWYG Markdown editor built from the ground up in C++ and Qt 6. Your Markdown file stays the single source of truth, rendered as a page you edit directly: no split panes, no preview pane, no typing lag.

常见问题

已有的 Markdown 文件能直接打开吗？

可以，直接打开现有的 .md 文件即可，无需导入或转换。切换到源码模式，可以查看和修改原始 Markdown。

支持哪些导出格式？

可以直接导出 PDF、HTML 和 PNG。导出 Word、EPUB 等格式时，需要另行安装 Pandoc。

可以自定义主题吗？

内置 GitHub、Newsprint、Night、Pixyll 和 Whitey 五款主题，也可以导入自己编写的 CSS 主题。

需要付费吗？

免费使用，源码采用 MIT 许可。你可以在 GitHub 查看源码、反馈问题或参与开发。
